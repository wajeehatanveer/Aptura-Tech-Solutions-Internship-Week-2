# 🚀 Aptura Tech Solution – Week 2

## Python Internship – Batch 3

Week 2 of the Aptura Tech Solution Python Internship focuses on building practical Python applications involving expense management, API data processing, data persistence, and interactive Streamlit interfaces.

Two projects were completed during this week, covering expense tracking and API-based data processing.

---

## 📌 Projects

### 💰 Task 1 – CLI Expense Tracker

A Python-based Expense Tracker designed to manage and organize daily expenses through a Command-Line Interface (CLI), with an additional interactive Streamlit frontend.

**Key Features:**

- Add expenses
- View all expenses
- Search expenses by category or description
- Filter expenses by category
- Calculate monthly expense totals
- Delete expenses
- JSON-based data persistence
- Input validation
- Error handling
- Expense dashboard
- Expense breakdown chart
- Interactive Streamlit interface

**Technologies:** Python, Streamlit, JSON, Object-Oriented Programming

---

### 📊 Task 2 – API Data Processing Script

A Python-based application that fetches JSON data from a public API, processes and cleans the retrieved data, calculates summary statistics, and exports the processed results to CSV.

An interactive Streamlit frontend was also developed to display and analyze the processed data.

**Key Features:**

- Fetch data from a public JSON API
- Extract selected fields
- Clean and process API data
- Calculate summary statistics
- Count total records
- Calculate unique users
- Calculate average title and body length
- Export processed data to CSV
- API and error handling
- Interactive data table
- CSV download option
- Streamlit dashboard

**Technologies:** Python, Requests, Pandas, Streamlit, JSON, CSV

---

## ▶️ How to Run

Install the required dependencies:

```bash
pip install -r requirements.txt
```

### 💰 Task 1 – CLI Expense Tracker

Open the Task 1 folder and run the CLI version:

```bash
python cli.py
```

To run the Streamlit interface:

```bash
streamlit run app.py
```

---

### 📊 Task 2 – API Data Processing Script

Open the Task 2 folder and run:

```bash
python api_processor.py
```

To launch the Streamlit interface:

```bash
streamlit run app.py
```
